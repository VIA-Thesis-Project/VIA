\# Environmental Bundle - Huaura



Área de estudio:

Provincia de Huaura, Lima, Perú.



Este directorio contiene los datos geoambientales preparados

para la ejecución de CropSuiteLite.



\## Componentes



\- boundary:

&#x20; límite provincial utilizado para validación espacial.



\- climate:

&#x20; variables climáticas requeridas por CropSuiteLite.



\- soil:

&#x20; propiedades edáficas requeridas.



\- terrain:

&#x20; modelo digital de elevación.



\- masks:

&#x20; máscaras espaciales.



\- processed:

&#x20; datos preparados para consumo del motor.



\- outputs:

&#x20; resultados generados.
